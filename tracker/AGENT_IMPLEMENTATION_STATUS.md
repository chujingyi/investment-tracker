## 定位与结构

自用投资研究与监控 Agent。Flask 管业务与页面，独立 Python Worker 管后台任务，SQLite/libSQL 存任务、事件、工具结果与审批。无需 Dify、MQ 或多 Agent 框架。

用户请求 → queued → Worker 原子领取 → prepare / agent_loop / result 步骤记录 → 模型与工具循环 → 等待逐项审批或交付结果。

已有工具为长桥行情、已同步持仓/成交、本地推荐与事件、框架全文检索。尚未内置 SEC/公司公告全文抓取；当前不能声称完成基本面证据核验。

## 本轮已实现

- 聊天、晨报、研究、复盘接口返回 202 与 task_id，网页不执行长模型循环。页面轮询任务，刷新/关闭不取消任务。
- 原子任务领取、租约、取消入口与终止状态保护。中断任务明确失败，禁止自动重放可能产生副作用的写入。
- 10个工具的输入校验、读写权限边界；写入通过待审批队列。工具结果保存 result_json，保留来源与时间字段。
- 审批绑定 task_id/run_id；所有动作批准后才完成。写入和审批状态在同一事务中提交，重复/并发批准仅执行一次。
- 写入失败回滚，任务失败；拒绝后异步修正一次。若已有部分批准动作，不自动重跑，防止重复写入。提案超过24小时必须重新生成。
- 到期复盘、临近日历、价格状态扫描；兼容 pending/upcoming。retry 可再次消费；事件和任务创建在同一事务；状态持续不变不重复提醒。
- 美东工作日 09:00 / 16:20 调度，自动转换夏令时；后者在收盘后刷新并入队晨报。独立每5秒消费人工任务。
- 日报按日期去重；监控结果必须包含合法 notify/reason 才会产生提醒。自动通知为工作流确定性投递，与聊天中的写工具审批不同。
- 运行前及轮间检查软 token 预算，HTTP超时/重试与轮次限制，补计收尾调用；按运行时配置保存估算单价。
- 当前使用代码定义的场景模板与共享循环，并记录执行阶段；不宣称具备通用DAG编排、动态规划或多个 Agent 协作。

## 评估口径

1. **工程回归**：独立临时库、禁止外网的测试，验证工具循环、审批事务、队列、取消、事件、迁移和统计。通过不代表真实模型质量已达标。
2. **历史推荐表现**：`python -m agent.cli eval`；7/30/60自然日，必须覆盖完整窗口，取目标日前4天内最后收盘价。首次保存样本及价格快照，后续使用同一数据；`--fresh` 显式重建。止损/目标/等待线指标仅表示收盘价触线，不表示盘中成交、先后次序或实际收益。观察档也不是已买入组合。
3. **Agent输出契约**：固定合成案例 `agent/evaluation_cases.json`。将真实模型结果整理为 responses.json，运行 `python -m agent.cli quality-eval responses.json`，检查结论、事实字段和证据ID。缺失案例算失败，未知引用算失败。此项不调用模型、不默认生成虚构分数；解释质量仍需人工复核。

输出样例（每个案例一项）：

```json
[{"case_id":"stale_quote","verdict":"insufficient_evidence","evidence_ids":["quote_old"],"facts":{}}]
```

这是单个案例格式，完整评测必须提交全部案例响应。模型比较需要同一案例、同一证据、固定版本分别生成真实响应，记录模型/提示词版本后再比较。

## 明确限制与后续验收

- 日 token 预算是轮间软限制：单次响应可能超预算，且不同进程并发不作硬配额预留；默认单 Worker。费用只是估算，不处理供应商缓存折扣或实际账单差异。
- 时间预算在循环/HTTP边界检查，不是任意 SDK 的可强杀执行沙箱。取消也在执行边界生效。需要硬超时应使用独立子进程执行工具。
- 任务有持久状态及阶段记录，但没有逐工具的完整模型上下文检查点；进程中断后安全失败，不宣称自动断点续跑。
- 调度处理美东周末和夏令时，不内置交易所节假日/提前收盘日历；休市日允许运行，工具必须提示数据时效。
- FTS/LIKE 是关键词检索，中文分词、长文分块与召回质量需单独评估；没有向量检索或跨会话长期记忆学习。
- Basic Auth + API Key 适合自用，不是企业多租户权限体系。部署公网须使用 HTTPS、强密码与反向代理；Compose 默认只绑定本机。
- 工程测试使用临时库；额外调用真实模型验证了合成工具循环和4个合成契约案例。不代表实际研究质量通过。没有迁移真实数据库、启动线上服务或验证Turso远端写事务。
- Docker 配置做静态检查；实际构建和启动、配置真实模型、数据来源联调仍需部署环境验收。
